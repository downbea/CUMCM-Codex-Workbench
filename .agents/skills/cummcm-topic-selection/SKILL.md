# 多题预分析与动态 PoC 选题


## Mandatory operating rules

Read project state, decision log, interaction log, and the directly required artifacts before acting. Write outputs to disk and return a compact change report. Never use chat memory as the only source of project state.

Respect human gates, source traceability, relative-path configuration, Git worktree isolation, and stale-artifact propagation. Do not perform destructive operations without explicit confirmation.


## Workflow

Analyze every available problem. For each, inspect attachments, run a basic data audit, identify key unknowns, retrieve related models, and execute a time-boxed baseline PoC. Dynamically allocate more budget to promising but uncertain problems and stop clearly infeasible tracks early.

Compare data availability, model fit, innovation space, compute cost, paper narrative, dependencies and risks. Produce a comparable report, then stop for human topic selection.
