# CUMCM-Codex-Workbench

“国赛数学建模 Codex 工作台”是面向全国大学生数学建模竞赛的本地工作流仓库。它采用“总控 Skill + 专业子 Skills + 确定性 Python 工具 + Obsidian 全局知识库 + 人工确认关卡”的架构。

## 两个主入口

知识学习模式负责批量导入 PDF/Markdown 论文、解析与联网补充、代码验证、集中人工审核和正式入库。

比赛建模模式负责多题并行预分析、动态 PoC 选题、赛题导入、数据审计与清洗、候选模型比较、人工确认、Python 实现、结果冻结、论文增量写作、Word/PDF 生成、三重审计和提交包打包。

## 首次安装

```powershell
.\setup.ps1
.\doctor.ps1
```

安装完成后，在 Windows 版 Codex App 中打开本仓库，直接说：

```text
启动国赛数学建模工作台，并读取当前项目状态。
```

## 关键原则

- 原始数据永不覆盖，清洗规则必须可逆且经人工确认。
- 每个小问先建立 Baseline，再用重复实验论证复杂模型是否值得采用。
- 主模型、清洗数据、最终结果和论文定稿均必须人工确认。
- 数据、模型、代码、数字、图表和论文段落通过依赖图进行失效传播与增量重算。
- Markdown 是论文唯一正文源，Word 只在最终阶段生成并人工微调。
- 三个独立审计均通过，或按分级规则完成风险接受后，才可进入最终定稿。
